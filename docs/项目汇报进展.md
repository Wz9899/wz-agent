## 关键决策（供汇报引用）

- **判断归模型，不归代码**：软路由（prompt）错判还能 ask_user 找回，硬路由（if-else）错判直接丢功能。
- **文件即状态，零记忆**：跨会话状态 = spec.md（需求）+ PROGRESS.md（进度）。
- **写操作不并行**：并行只做读；写隔离等真实冲突再引入。
- **git 边界**：版本控制、回滚由用户自己用 git 管，harness 零 git。
