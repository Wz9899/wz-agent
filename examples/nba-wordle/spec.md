# NBA 神秘球员猜猜乐 · 更新数据库到最新 需求规格

## 概述
本项目的目标是对已完成的纯前端网页游戏《NBA 神秘球员猜猜乐》（index.html）的内置球员数据库进行更新，使其反映当前（实时）的 NBA 球员信息。核心动作是用虎扑数据源的实时球员详情对 index.html 内硬编码的 185 名球员进行字段级刷新，重点是修正转会（如杜兰特、戴维斯等已更换球队）和年龄/NBA年限等自动演进的数值，不改变游戏本身的玩法与代码结构。

## 功能需求

### 核心功能：更新内置球员数据
- 保留 index.html 中现有的 185 名球员作为基础名单，不增删球员主体（维持"现役主力"池规模）。
- 对每名球员抓取虎扑详情页，刷新以下字段到最新实时状态：
  - **球队（team）**：以虎扑详情页"球队"字段为准，自动反映最新转会。
  - **位置（position）**：以虎扑详情页"位置"字段为准。
  - **年龄（age）**：根据虎扑详情页"生日"，按当前日期计算周岁。
  - **国籍（nation）**：以虎扑详情页"国籍"字段为准。
  - **NBA年限（nbaYears）**：按「当前赛季年份 − 选秀年份」计算（联赛年数，客观可靠）。
- 对以下两项不做重抓，保留 index.html 现有值（旧数据仍大体可靠，且虎扑无可靠现成字段）：
  - **季后赛次数（playoffs）**：保留原值。
  - **冠军次数（championships）**：保留原值。

### 次要功能
- 抓取过程以脚本（Node.js）自动完成，输出更新后的数据，供人工替换进 index.html。
- 抓取应尽量健壮：详情页失败/缺字段时回退到原值，避免因个别页面失败导致数据丢失。

### 不做的事
- 不改变游戏玩法、规则、UI、7 次猜测机制。
- 不从虎扑重新统计季后赛次数/冠军次数。
- 不新增数据库字段、不增删球员（除非个别球员已退役且虎扑详情页完全失效）。

## 技术栈
- Node.js（编写抓取脚本，复用项目内已有 fetch 风格：https + User-Agent，带超时）
- 数据源：https://nba.hupu.com/players/{slug}-{id}.html 球员详情页
- 名单来源：项目内已有 _roster_*.txt（含 slug|id|中文名）与 _page_*.html
- 目标文件：index.html（替换 PLAYERS 数组中的 206–392 行）

## 数据模型
沿用 index.html 现有字段结构：
- id: number（保持原有 id 不变）
- nameZh: string（中文名，保持）
- nameEn: string（英文名，保持）
- team: string（中文球队名，更新）
- position: string（中文位置，更新）
- age: number（周岁，更新）
- nation: string（国籍，更新）
- nbaYears: number（NBA年限，更新）
- playoffs: number（保持原值）
- championships: number（保持原值）

数据来源对应关系：
- 球队 ← 详情页「球队」
- 位置 ← 详情页「位置」（如 "F-G" → 需映射到 中/前锋/后卫中文，映射规则详见实现：C→中锋、F→前锋、G→后卫、F-G/F/C-G→按主位）
- 年龄 ← 详情页「生日」按当前日期计算周岁
- 国籍 ← 详情页「国籍」
- NBA年限 ← 详情页「选秀」年份 → 当前赛季年数

## 交互设计
- 本任务为后台数据更新，不涉及用户交互界面改动。
- 交付物供开发者替换进 index.html 后，玩家在游戏下拉中看到更新后的球队/年龄等信息。

## 边界条件 & 约束
- 抓取失败容错：单球员详情页请求失败或字段解析失败时，该球员回退到原 index.html 数据，并打印告警日志。
- 时区/日期：年龄按当前系统日期 2026 年计，周岁按生日越过与否精确计算。
- 位置映射：虎扑英文位置缩写（C/F/G/F-C/F-G）要映射为游戏现有的中文位置值（中锋/前锋/小前锋/大前锋/得分后卫/控球后卫/后卫/前锋）。
- 性能：185 名球员逐个串行或小并发抓取，设置超时与重试，避免被封。
- 网络可用性依赖：虎扑详情页当前可访问（已实测 200），但抓取需自带 User-Agent。

## 交付物
- 更新后可直接替换的球员数据块（PLAYERS 数组内容，写回 index.html 206–392 行）
- 抓取脚本（新建，如 _update_roster.js）
- 抓取过程的日志/中间产物（方便核对每名球员更新前后的差异）
- 更新后的 index.html（应用最新数据）
