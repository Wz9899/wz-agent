# NBA 神秘球员猜猜乐

这是 **wz-agent 自动生成的一个示例项目**（纯前端游戏）。

## 玩法

系统随机选定一名现役 NBA 球员作为"神秘目标"，玩家在最多 7 次机会内猜球员，每次猜完读取属性对比提示（数值属性给"高于/低于/相同"，分类属性给"匹配/不匹配"）来缩小范围，猜中获胜；7 次未中揭晓答案。

## 运行

直接用浏览器打开 `index.html` 即可（纯前端，无后端、无网络依赖，数据内置）。

## 如何用 wz-agent 生成类似项目

```bash
python src/main.py
# 输入需求 → 澄清 → 编码
```

## 文件

- `index.html` — 完整游戏（内联样式 + 逻辑 + 球员数据，单文件）
- `spec.md` — 该游戏的需求规格（wz-agent 澄清阶段产出）
